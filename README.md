# advent-of-code-2026

[Advent of Code 2026 Solutions](https://adventofcode.com/2026). This year I'm
switching back to TypeScript, to see if it's less frustrating than it was a
couple of years ago.

The biggest difference between this year and previous years is how almost
unavoidable agentic coding is. Especially considering that even Google searches
just drop you into an AI chat that's hard to ignore, I'm going to do my research
by using AI chat in read-only mode. I'll also try to see if the agent can do the
tedious work of updating the unit tests based on the examples each day.

Just as I did [last year](https://github.com/leedm777/advent_of_code_2025), I am
going to do more practice with prior year's puzzles, so I've generalized the
scripts and runners to handle puzzles from any year.
